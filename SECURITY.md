# Security Policy

PortfolioLens Community is a mock-data frontend project. It should never contain private production credentials or proprietary backend logic.

## Please Do Not Publish

- API keys, tokens, or secrets
- `.env` or `.env.local`
- Private backend URLs
- Internal prompts
- Proprietary prediction or scoring logic
- Paid market data provider code
- Real user or portfolio data

## Reporting

Please report security concerns privately to the repository owner. Do not open public issues containing secrets or exploitable details.

## Before Publishing

Run `git status --short` and your preferred secret-scanning tool before publishing.

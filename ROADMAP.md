# Roadmap

## Short Term

- Add screenshots for the dashboard, portfolio, watchlist, and stock research views.
- Add small interaction tests for tab switching and mock data rendering.
- Add optional light theme support.
- Add a tiny Python test for mock analytics report generation.

## Community Enhancements

- Import/export sample portfolios as local JSON.
- More technical indicator display variants.
- Additional example watchlists for different investing styles.
- Accessibility and keyboard navigation pass.

## Out of Scope

- Real trading, brokerage, or investment advice features
- Private prediction models
- Proprietary scoring logic
- AI provider prompts or completions
- Paid market data provider integrations
- Production authentication and user data storage

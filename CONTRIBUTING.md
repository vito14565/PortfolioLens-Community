# Contributing

Thanks for helping improve PortfolioLens Community.

## Local Development

```bash
npm install
npm run dev
```

Run a production build before opening a pull request:

```bash
npm run build
```

## Safety Rules

- Do not commit `.env`, `.env.local`, API keys, tokens, private URLs, or credentials.
- Do not add proprietary prediction logic, model code, internal prompts, or paid provider integrations.
- Use mock data for examples and tests.
- Do not include real portfolio, watchlist, account, alert, or chat data.

## Pull Requests

- Keep changes focused.
- Update docs when setup or architecture changes.
- Include screenshots for visible UI changes when possible.
- Explain whether a change is UI-only, data-only, or documentation-only.
